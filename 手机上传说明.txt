《人文札记》· 手机上传版（一层平铺，无子文件夹）
================================================

这个文件夹里的所有文件都在同一层，手机上可以「全选」一次性上传，不需要建文件夹。

【重要】必须一起上传的文件：
  · index.html（首页）
  · 7 个文章页：nearby.html / strangers.html / memory.html / mianzi.html / crowds.html / efficiency.html / trickle.html
  · 7 张封面：cover-nearby.svg 等（同名对应）
  · 其余页面：archive.html / tags.html / series.html / favorites.html / history.html / guestbook.html / about.html / 404.html
  · style.css / app.js / data.js / config.js
  · rss.xml / sitemap.xml / robots.txt
  合计 32 个文件（本说明不用上传也可以）

【千万别漏】config.js —— 留言板的后端配置就在这个文件里，漏传它留言板会显示「尚未配置」。

上传方法（GitHub 手机网页版）
  1. 注册 GitHub 并新建一个公开仓库（例：renwen-zhaji）
  2. 仓库页 → Add file → Upload files
  3. 点选择文件 → 进到这个文件夹 → 全选（32 个）→ 确认上传
  4. 页面底部点 Commit changes
  5. 仓库 Settings → Pages → Source 选 Deploy from a branch → main / (root) → Save
  6. 等 1–3 分钟，访问 https://你的用户名.github.io/renwen-zhaji/

（如果走腾讯云 EdgeOne：直接上传 renwen-zhaji-site.zip 那个压缩包即可，不用解压。）

说明
  · 文件名是平铺的：文章就是 nearby.html，封面是 cover-nearby.svg
  · 本版为 v6：留言板带「断线暂存、联网自动补发」——后端连不上时访客写的内容先存在他本机，恢复后自动补发
  · 留言存在 Supabase 数据库（配置见 config.js），访客免登录即可留言
